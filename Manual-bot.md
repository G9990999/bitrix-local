# Manual-bot.md — Telegram-бот

## Обзор

Telegram-бот на базе **LangChain + GigaChat** обеспечивает автоматизацию работы службы поддержки отдела работы с тендерными заявками.
Бот отвечает на текстовые запросы менеджеров, выдавая пошаговые инструкции по работе в Bitrix24.
Также принимает события из Bitrix24 через вебхуки и уведомляет команду в Telegram-группах.

---

## Архитектура

```
Менеджер (Telegram)
       │
       ▼
tender-bot (FastAPI, порт 8000/3102)
       │
       ├── /webhook/telegram   ← Telegram Bot API (входящие сообщения)
       ├── /bitrix/webhook     ← Bitrix24 REST события (ONCRMDEALADD и др.)
       └── /health             ← Проверка работоспособности
       │
       ├── prompts.py          ← Шаблонные ответы (быстро, без API)
       └── GigaChat API        ← LangChain для свободных запросов
```

## Настройка

### 1. Регистрация бота в Telegram

1. Откройте @BotFather в Telegram.
2. Отправьте команду `/newbot`.
3. Укажите имя (например, `Tender Bot`) и username (например, `tender_bot`).
4. Скопируйте полученный **TELEGRAM_TOKEN**.

### 2. Настройка переменных окружения

Скопируйте файл конфигурации:
```bash
cp server-ansible/home/tender-bot/.env.example server-ansible/home/.env
```

Заполните значения:
```env
TELEGRAM_TOKEN=1234567890:ABCdefGHIjklMNOpqrSTUvwxYZ
TELEGRAM_CHAT_ID=-1001234567890
GIGACHAT_CREDENTIALS=<Base64 от Client_ID:Client_Secret>
GIGACHAT_SCOPE=GIGACHAT_API_PERS
```

Получить `GIGACHAT_CREDENTIALS`:
1. Зарегистрируйтесь на [developers.sber.ru](https://developers.sber.ru)
2. Создайте проект GigaChat API
3. Скопируйте `Client ID` и `Client Secret`
4. Закодируйте: `echo -n "CLIENT_ID:CLIENT_SECRET" | base64`

### 3. Запуск

```bash
cd server-ansible/home
docker compose up -d tender-bot
```

### 4. Настройка Webhook в Bitrix24

После запуска бота зарегистрируйте вебхук в Bitrix24:
```bash
docker exec bitrix-php bx bx:webhook-reg ONCRMDEALADD
docker exec bitrix-php bx bx:webhook-reg ONCRMDEALUPDATE
docker exec bitrix-php bx bx:webhook-reg ONCRMDEALDELETE
```

## Функциональность бота

### Режимы работы

| Режим | Описание |
|-------|----------|
| **Шаблонные ответы** | По ключевым словам — быстро, без API GigaChat |
| **GigaChat (LLM)** | Свободные вопросы — через LangChain → GigaChat API |
| **Bitrix24 Events** | Входящие события из CRM → уведомление в Telegram |

### Команды бота

| Команда | Описание |
|---------|----------|
| `/start` | Приветствие и подсказки |
| Любой текст | Поиск по шаблонам → GigaChat |

### Сценарий 1: Создание заявки на расходование ДС

**Запрос:** `создать заявку на расходование ДС`

**Ожидаемый ответ:** Пошаговая инструкция создания финансовой заявки в CRM (5–7 шагов).

## Методика тестирования

### Ручное тестирование

1. **Запустите стек:**
   ```bash
   docker compose up -d
   ```

2. **Откройте Telegram**, найдите своего бота по username.

3. **Отправьте `/start`** — должно прийти приветствие со списком подсказок.

4. **Проверьте каждый из 10 сценариев** выше, отправив запрос и сверив ответ с ожидаемым.

5. **Проверьте свободный вопрос** (при наличии GIGACHAT_CREDENTIALS):
   ```
   Как мне добавить нового сотрудника в тендерный отдел?
   ```
   Ожидается связный ответ от GigaChat.

### Автоматическое тестирование

Запустите тесты:
```bash
docker run --rm -v $(pwd)/tender-bot:/app -w /app python:3.12-slim \
  sh -c "pip install -q pytest && pytest tests/ -v"
```

### Проверка вебхуков Bitrix24

```bash
# Проверить зарегистрированные вебхуки
docker exec bitrix-php bx bx:webhook-reg

# Симулировать событие из Bitrix24
curl -X POST http://localhost:3102/bitrix/webhook \
  -d "event=ONCRMDEALADD&data[FIELDS][ID]=42"
```

### Проверка /health endpoint

```bash
curl http://localhost:3102/health
# Ожидаемый ответ: {"status":"ok"}
```

## Переменные окружения

| Переменная | Обязательная | Описание |
|-----------|:---:|---------|
| `TELEGRAM_TOKEN` | ✅ | Токен от @BotFather |
| `TELEGRAM_CHAT_ID` | — | ID чата для уведомлений из Bitrix24 |
| `GIGACHAT_CREDENTIALS` | — | Base64(ClientID:Secret) для GigaChat API |
| `GIGACHAT_SCOPE` | — | Скоуп API (по умолчанию GIGACHAT_API_PERS) |
| `BITRIX_WEBHOOK_URL` | — | URL Bitrix24 в Docker-сети (по умолчанию http://bitrix-nginx) |
| `HANDLER_BASE_URL` | — | Внешний URL этого сервиса для Bitrix24 |

---

## Примечания

- Если `GIGACHAT_CREDENTIALS` не задан — бот работает только по шаблонным ответам.
- Шаблонные ответы срабатывают по частичному совпадению ключевых слов.
- Для production рекомендуется настроить HTTPS (Let's Encrypt или обратный прокси).
